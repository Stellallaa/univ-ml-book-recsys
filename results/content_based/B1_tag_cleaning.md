# B1 태그 정제

## 과정

A3의 `load_book_tags()`를 그대로 사용하고, `bookrec.data.tag_filter`에서 책장 태그만 추가로 제거합니다. 기존 로더와 다른 팀원의 파일은 수정하지 않았습니다.

- `filter_book_tags(tags, extended=False)`: 읽기 상태·소유·구매·매체 태그를 제거합니다.
- `filter_book_tags(tags)`: 위 규칙에 개인 평가·독서 연도 태그 제거를 추가합니다.
- `tag_filter_report(tags)`: 태그마다 책 수, count 합계, 제거 이유를 확인합니다.
- 소문자·공백·밑줄 정규화는 규칙 판정에만 적용하고, 결과의 원래 태그 이름과 행 순서는 유지합니다.
- 연도 규칙은 `2015-reads`, `read-in-2016`처럼 독서 기록임이 명시된 경우만 적용합니다. `1984`, `19th-century`는 남깁니다.
- `fiction`처럼 널리 쓰이는 내용 태그는 등장 빈도만으로 제거하지 않습니다.

- 전체 통계: `B1_filter_summary.csv`
- 제거 태그와 이유: `B1_removed_tags.csv`
- 실행 결과와 책별 사례: `notebooks/content_based/B1_tag_cleaning.ipynb`

## 검증

기존 테스트 22개와 B1 테스트 5개가 모두 통과했습니다. 내용 태그 보존, 책장·매체 제거, 확장 규칙 전환, 빈 입력·태그 처리, 입력 불변성, 제거 보고서의 집계를 확인했습니다. 실제 책 10,000권 모두 정제 후 태그가 남습니다.

## 한계와 다음 작업

명시적인 태그 목록과 제한된 연도 패턴을 쓰므로, 일치하지 않는 개인 책장 태그는 남을 수 있습니다. 모든 비내용 태그를 제거했다고 가정하지 않습니다. `favorites` 같은 태그는 취향 정보도 담을 수 있어 basic과 extended를 B4에서 비교합니다. 현재 통계만으로 추천 성능 개선을 주장하지 않습니다.

B2에서는 이 결과로 책 특징 행렬을 만들고, 행 순서를 `BOOK_IDS`와 일치시킵니다. B4의 비교 실험에는 동일한 데이터 분할과 평가 함수를 사용합니다.
