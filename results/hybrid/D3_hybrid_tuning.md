# D3 Hybrid 점수 결합 실험

## 방법

CB는 B4 선택 설정 C17, MF는 C2/C3 추천용 최종 설정(128 factors, neg_ratio 8, fold-in 정규화 10)을 사용했습니다. 모델별 점수 범위가 다르므로 사용자별 점수를 10,000권 카탈로그 안에서 백분위 순위로 바꾼 뒤 결합했습니다. 추천 시 평가 이력의 책은 기존 `Recommender.recommend()`에서 제외합니다.

다음 9개 후보를 비교했습니다.

- 고정 비율: MF 가중치 0.25, 0.50, 0.75
- 전환: 이력 3, 5, 10개부터 MF로 전환
- 점진 전환: 이력 1→5, 1→10, 3→10개 구간에서 MF 비율을 0에서 1로 선형 증가

모든 모델은 `split.train`으로 학습했습니다. 목표 점수는 `val` 1,000명(시드 42)의 NDCG@10과 `cold_tune` 2,500명의 이력 1·3·5·10 평균 NDCG@10을 같은 비중으로 평균했습니다. `test`/`cold_final`은 튜닝에 쓰지 않았습니다.

## 비교와 해석

같은 검증 코호트에서 단독 MF NDCG@10은 기존 독자 0.075703, 신규 독자 이력별 0.252929/0.270883/0.278353/0.295573이었습니다. 선택된 switch-at-3은 기존 독자에서 MF와 같고, 신규 독자 이력 1개에서는 CB 점수로 바뀌며 0.151777을 기록했습니다. 이력 3·5·10개에서는 MF와 같은 점수를 냈습니다.

따라서 switch-at-3은 **비교한 하이브리드 후보 중** 가장 높았지만, 전체 cold 평균 0.249146은 단독 MF 평균 0.274434보다 낮습니다. 신규 독자 이력 1개에서는 CB 단독 0.151777과 같아 MF 단독 0.252929보다 낮습니다. 이 실험에서는 하이브리드가 MF보다 성능을 높이지 않았고, CB 기반 전환의 cold-start 약점이 주요 원인입니다. 선택 설정은 결합 방식 후보 비교의 결과이며, MF 대비 성능 향상으로 주장하지 않습니다.

warm 검증은 CB/MF/선택 Hybrid 모두 동일한 996명의 정답 보유 표본을 사용했고, cold 검증은 각 이력 설정에서 2,500명을 사용했습니다. 파라미터 탐색 공간이 9개 후보로 제한되고 같은 검증 코호트로 설정을 선택했으므로, 선택 점수는 독립적인 성능 추정치가 아닙니다. 최종 test/cold_final은 아래 표에 별도로 보고합니다.

## 최종 홀드아웃 결과

선택된 switch-at-3 설정을 `train + val` 기준으로 적용해 공통 test/cold_final 분할에서 채점했습니다. warm test는 모든 사용자의 이력이 전환 기준보다 길어 MF와 같은 순위를 내므로 공통 MF 최종 점수를 재사용했습니다. 신규 독자는 이력 1개에서 CB, 3개 이상에서 MF를 사용합니다.

| 대상 | NDCG@10 인기순 | NDCG@10 CB | NDCG@10 MF | NDCG@10 Hybrid |
| --- | ---: | ---: | ---: | ---: |
| 기존 독자, test | 0.032039 | 0.042463 | 0.057218 | 0.057218 |
| 신규 독자, 이력 1개 | 0.233752 | 0.159614 | 0.256665 | 0.159614 |
| 신규 독자, 이력 3개 | 0.233752 | 0.169103 | 0.273512 | 0.273512 |
| 신규 독자, 이력 5개 | 0.233752 | 0.179504 | 0.283455 | 0.283455 |
| 신규 독자, 이력 10개 | 0.233752 | 0.221658 | 0.304823 | 0.304823 |

Hybrid는 기존 독자와 신규 독자 이력 3개 이상에서 MF와 같은 순위를 내며, MF보다 개선되지 않았습니다. 이력 1개에서는 CB로 전환되어 인기순과 MF 모두보다 낮습니다. 인기순보다는 기존 독자 및 신규 독자 이력 3개 이상에서 높았지만, 이력 1개 성능 저하가 있어 전체 상황에서 우월한 모델이라고 볼 수 없습니다. to-read 적중률은 이력 1개에서 인기순 0.01719보다 Hybrid 0.02494로 높았으므로, relevance 정의에 따라 결과가 달라집니다.

최종 CSV 원본은 `results/hybrid/cb_final_scores.csv`, `hybrid_warm_test.csv`, `hybrid_cold_final.csv`이며, 모든 알고리즘의 개선량을 포함한 비교표는 `results/final/holdout_comparison.csv`입니다.
