# content_based

content-based filtering 코드를 두는 곳입니다. 담당은 팀원 B입니다.

| 작업 | 하는 일 |
| --- | --- |
| B2 책 벡터 | 정제한 태그 등으로 책마다 특징 벡터를 만듦 |
| B3 CB 추천기 | 독자가 좋아한 책과 비슷한 책에 높은 점수를 주는 추천 모델 |
| B4 CB 설정 비교 | 태그, 가중 방식, 유사도 계산 방식 등을 바꿔 비교하고 최종 설정을 고름 |
| B5 책 군집 | 책 특징 벡터를 k-means로 묶고 군집별 대표 책을 뽑음 |

- B3의 추천 모델은 `Recommender`를 상속합니다(`../README.md` 참고). 평점이 1~3개뿐인 독자에게도 동작해야 합니다.
- B1 태그 정제는 데이터 정리 작업이라 `bookrec/data/`에 둡니다.
- B4 비교 실험은 `notebooks/`에서 하고, 재사용할 코드만 여기에 둡니다.
