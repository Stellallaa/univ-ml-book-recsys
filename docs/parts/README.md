# parts

발표 준비(S2)를 위해 각자 맡은 부분을 md로 정리하는 곳입니다. 팀원 D가 이 자료로 PPT를 만들고, 팀원 C가 대본을 통합합니다.

- 파일 하나에 한 사람의 파트를 정리합니다(예: `content_based.md`, `mf.md`).
- 이미지는 `docs/figures/`에 저장하고 md에서 경로로 넣습니다.
- 마감: 11/10(화) 밤

## 정리할 내용

```markdown
# 파트 이름 (담당 작업 ID)

## 과정
## 결과
## 결론
## 이미지
## 2분 발표 대본
## 어려웠던 점과 해결
## 개인별 배운 점
## 참고한 외부 코드·자료 (출처)
```
